# サーバー提供元さまへのお願い（ナイトだんどり / prod4）

いただいた本番環境（Ubuntu・Node 22・PostgreSQL 18・8032 番）で動かすにあたり、
こちらの権限では行えない点を3つお願いします。

## 1. PostgreSQL の役割（ロール）の作成　※必須

このアプリは Supabase と同じしくみ（PostgREST / GoTrue）で動くため、
`anon` `authenticated` `service_role` などの役割を使ってデータの見せ分けを行います。
`ai_labo_dbuser` には CREATEROLE が無いため、次のどちらかをお願いします。

- **A.** 一時的に `ALTER ROLE ai_labo_dbuser CREATEROLE;`（初期設定後に `NOCREATEROLE` へ戻して構いません）
- **B.** 同梱の `server/db/依頼_DB権限.sql` を superuser で実行（パスワード3つは別途お伝えします）

あわせて、`dandoriolivia` の持ち主が `ai_labo_dbuser` であることをご確認ください
（違う場合：`ALTER DATABASE dandoriolivia OWNER TO ai_labo_dbuser;`）。

## 2. 外向きの通信の許可　※必須

サーバーから次の先へ HTTPS で出られる必要があります。

| 先 | 用途 |
|---|---|
| `github.com` / `release-assets.githubusercontent.com` | 部品（PostgREST・GoTrue・Deno）の取得（初回のみ） |
| `registry.npmjs.org` | npm（初回のみ） |
| `esm.sh` | サーバー処理が使うライブラリ（初回起動時） |
| `api.line.me` | LINE の返信・送信 |
| `api.anthropic.com` / `generativelanguage.googleapis.com` / `api.openai.com` | AI の下書き（使うもののみ） |
| `api.resend.com` または `api.sendgrid.com` | メール送信（使う場合） |
| `pixabay.com` | 背景写真の検索（使う場合） |

## 3. nginx（8032 への転送）の設定　※確認

次の3行が入っているかご確認ください。無ければ追加をお願いします。

```nginx
client_max_body_size 50m;                    # 書類のアップロード（最大 50MB）
proxy_read_timeout   150s;                   # AI の下書き（長いと 1〜2 分）
proxy_set_header     X-Forwarded-Proto $scheme;
```
