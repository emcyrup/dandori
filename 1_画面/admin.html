スタッフ

スタッフの新規追加は、この画面からはできません。ログイン用のアカウントを先に作る必要があるためです。
Supabase → Authentication → Users でアカウントを作ってから、SQL Editor で select * from app.link_staff('メール', '名前', 'staff'); を実行してください。

CSVは、1行目を見出しにしてください。雛形の見出しに合わせると、そのまま読み込めます。
PDF・写真（手書きの名簿や給与台帳）は、こちらでお預かりして、1行ずつ起こしてからお返しします。
